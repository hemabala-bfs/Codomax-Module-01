# Codomax Digital Solutions – Module 01: Introduction to AI & Python

Welcome to the repository for **Module 01: Introduction to AI & Python**, completed as part of the internship at **Codomax Digital Solutions**.

---

## 📌 Project Overview
This repository contains the foundational coursework, theoretical notes, and working code for Module 01. The objective is to establish a strong technical understanding of Artificial Intelligence concepts (AI, ML, and Deep Learning) and develop core problem-solving proficiency using the Python programming language.

---

## 🎯 Learning Objectives
1. Understand the fundamental concepts and principles of Artificial Intelligence and Machine Learning.
2. Distinguish clearly between Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL).
3. Explore practical, real-world AI applications across healthcare, agriculture, education, banking, and transportation.
4. Master core Python programming fundamentals:
   - Variables and storage
   - Fundamental data types (`int`, `float`, `str`, `bool`) and type inspection
   - Decision-making with conditional statements (`if`, `elif`, `else`)
   - Repetition and iteration using `for` and `while` loops
   - Code modularity with reusable functions and error handling
   - Structured collections using Python lists
5. Write, test, and document clean, PEP 8-compliant Python code.

---

## 💻 Technologies Used
- **Programming Language:** Python 3.14 (Compatible with Python 3.8+)
- **Coding Standard:** PEP 8 Style Guide for Python Code
- **Version Control:** Git & GitHub
- **Environment:** Visual Studio Code / Terminal

---

## 📜 Python Programs Included

| File Name | Description | Key Concepts Demonstrated |
| :--- | :--- | :--- |
| `01_variables.py` | Stores and displays student profile details (name, age, course, college). | Variable assignment, descriptive naming, f-strings formatting. |
| `02_data_types.py` | Declares variables of different data types and displays their data types. | `int`, `float`, `str`, `bool`, and `type()` function. |
| `03_conditional_statements.py` | Implements an interactive student grading system. | Input handling, range validation (0–100), `if`, `elif`, and `else`. |
| `04_for_and_while_loops.py` | Prints numbers from 1 to 5 and calculates their sum using two loop types. | `for` loop with `range()`, `while` loop with counter, cumulative sum. |
| `05_functions.py` | Implements arithmetic operations (+, -, *, /) as reusable functions. | Function definition (`def`), arguments, `return`, zero-division safety. |
| `06_lists.py` | Manages a list of student marks, performs modifications, and calculates average. | `append()`, `remove()`, `sort()`, iteration, `sum()`, and `len()`. |

## 🚀 How to Execute the Programs

### Prerequisites
Ensure Python is installed on your system. You can verify your installation by running:
```bash
python --version
```

### Execution Steps
1. Clone or navigate to the repository directory:
   ```bash
   cd Codomax-Module-01
   ```

2. Run any program individually from your terminal:

   * **Run Program 01 (Variables):**
     ```bash
     python Python_Programs/01_variables.py
     ```

   * **Run Program 02 (Data Types):**
     ```bash
     python Python_Programs/02_data_types.py
     ```

   * **Run Program 03 (Conditional Statements):**
     ```bash
     python Python_Programs/03_conditional_statements.py
     ```
     *(Enter student marks when prompted, e.g., 85)*

   * **Run Program 04 (Loops):**
     ```bash
     python Python_Programs/04_for_and_while_loops.py
     ```

   * **Run Program 05 (Functions):**
     ```bash
     python Python_Programs/05_functions.py
     ```

   * **Run Program 06 (Lists):**
     ```bash
     python Python_Programs/06_lists.py
     ```
